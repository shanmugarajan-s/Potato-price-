# 🥔 Potato Price Prediction — ML Assignment 2

A machine-learning project for **potato mandi price prediction** using time-series features, seasonal patterns and weather variables, with natural-language prompt extraction, a context-aware retrieval-augmented chat assistant, and an interactive dashboard.

## Assignment requirements covered

| Requirement | Implementation |
|---|---|
| Predict an agricultural commodity price | Potato modal price prediction |
| Time-series forecasting | Market-wise Lag1, Lag2 and 4-week rolling mean |
| Seasonal patterns | Winter, Summer, Monsoon, Post-Monsoon |
| Weather data | Rainfall, temperature and humidity |
| Varied hyperparameters | Random Forest sweep over `n_estimators` and `max_depth` |
| Evaluation metrics | MAE, RMSE and R² |
| Prompt-based extraction | Six documented natural-language prompts |
| RAG chat | TF-IDF retrieval + conversation context + response generation |
| Dashboard | Charts, model metrics, hyperparameter table and chat UI |

## Dataset

The supplied prepared dataset contains:

- **16,016 records**
- **22 states**
- **305 markets**
- Weekly observations from **2025-10-03 to 2026-09-25**
- Potato Min/Max/Modal prices
- Season
- Rainfall
- Temperature
- Humidity

### Data-provenance limitation

The repository intentionally keeps the data-provenance limitation visible. The 52-week historical series and weather variables are a **documented simulation anchored to a real market-price snapshot**. The original snapshot used to construct it is not included in this repository.

Therefore:

> The model metrics are valid for this supplied academic dataset, but they must not be presented as proof of production forecasting accuracy on genuine multi-year market history.

For real deployment, retrain using genuine multi-year mandi prices and observed weather data.

## Model workflow

```text
Prepared Dataset
      ↓
Data Validation
      ↓
EDA
      ↓
Lag1 / Lag2 / Rolling 4-week Features
      ↓
Chronological Train/Test Split
      ↓
Linear / Ridge / Polynomial / Random Forest
      ↓
Hyperparameter Sweep
      ↓
TimeSeriesSplit + GridSearchCV
      ↓
Evaluation: MAE / RMSE / R²
```

The latest **8 weeks** are used as the chronological held-out test period.

## Prompt-based data extraction

The notebook explicitly documents these prompts:

1. “What is the current potato price in Tamil Nadu?”
2. “What is the average potato price in Punjab during monsoon?”
3. “How much does potato cost during winter?”
4. “Which states have the highest potato prices?”
5. “Is the potato price trend rising or falling?”
6. “What is the price in Uttar Pradesh in post-monsoon season?”

These prompts query/retrieve information from the collected dataset. They are not claims that the historical dataset itself was generated by an LLM.

## RAG chat assistant

The final notebook implements a lightweight academic RAG pipeline:

```text
Dataset
  ↓
Data-derived summary documents
  ↓
TF-IDF vectorization
  ↓
Cosine-similarity retrieval
  ↓
Conversation context (state / season)
  ↓
Response generation
```

The assistant can understand follow-ups such as:

```text
User: What is the current potato price in Tamil Nadu?

Bot: [Tamil Nadu price]

User: And what about during monsoon there?

Bot: [Tamil Nadu + Monsoon price]
```

No external LLM API is required.
